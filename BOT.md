# Подбор автомобиля и переписка в Telegram

## Работа менеджера

1. В мини-приложении или настольной CRM создайте заявку. Проверьте согласие клиента, модель и открытые характеристики для поставщиков. Исходное сообщение, контакт и бюджет остаются в CRM. При сохранении сервер открывает по одному диалогу на активного поставщика марки и ставит запросы в очередь. Если марка отсутствует в названии, укажите её отдельно. Для старой заявки поиск можно запустить в разделе «Подбор и КП».
2. Поставщик предварительно открывает бота и нажимает Start. Он отвечает на сообщение запроса или выбирает диалог через /threads. Альбом предназначен для одной машины. Подпись можно отправить отдельно ответом на фотографию. Ответ сохраняется в заявке, даже когда у неё временно нет ответственного. Изображения поступают в закрытое хранилище в PostgreSQL, в нём используются JPEG-копии Telegram до 260 КБ.
3. В карточке заявки откройте «Подбор и КП». В мини-приложении кнопка называется «Поставщики и КП». Выберите диалог, при необходимости задайте вопрос поставщику. «Проверить и рассчитать» открывает вариант с данными поставщика и его тарифом. Проверьте модель, год, пробег, валюту, закупку и расходы. Для импорта укажите курс, затем назначьте цену клиенту. Суммы таможенных платежей задаёт дилер.
4. Просмотрите фотографии и отметьте подходящие для клиента. Проверка логотипов и контактов на изображениях ручная. Сохраните вариант. Для изменения набора фото откройте «Изменить». Сервер проверяет принадлежность фотографий диалогу.
5. Выберите готовые варианты и нажмите «Создать КП». Можно получить текст или PDF из сохранённой версии. После самостоятельной отправки клиенту нажмите «Отметить отправку». При следующем открытии раздела появится форма «Реакция клиента на КП». Сохраните результат разговора, причину отказа или дату повторного звонка.
6. В «Команда» владелец или администратор добавляет участника с ролью «Поставщик». В «Поставщики» включаются марки и настраиваются валюта и расходы. Там же задаются сроки напоминаний. Настройки стоимости принадлежат конкретному дилеру. Профиль независимого поставщика доступен другому дилеру под псевдонимом.

## Входящие сообщения

Для свободного текста бот использует текстовую модель для маскирования персональных данных и создания черновика. При отсутствии ключа поставщик может ответить по образцу для модели из запроса. Для отрицательного ответа подходит «Нет в наличии». Фотографии без подписи также принимаются.

```text
Год: 2022
Пробег: 35000 км
Цена: 1800000 JPY
Срок: 45 дней
```

Команды менеджера в личке с ботом принимаются текстом при подключённой текстовой модели. Бот показывает черновик перед подтверждением. /requests и /threads переключают заявку и переписку. Голосовые сообщения получают подсказку написать текст.

## Подключение окружения

- Схемы применяются в порядке `schema.sql`, `workspace.sql`, `crm.sql`, `domain.sql`, `contacts.sql`, `bot.sql`, `workflow.sql`. При обновлении существующей установки повторно примените изменённые определения в `domain.sql` и `bot.sql` перед `workflow.sql`.
- Нужны обе Edge Functions, `api` и `telegram-bot`, и frontend из той же версии. Для `api` включена проверка JWT на шлюзе, для Telegram webhook и worker используются отдельные секретные заголовки.
- Серверные переменные бота: `BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` и `BOT_WORKER_SECRET`. Последние два секрета должны быть разными, длиной от 32 символов. `OPENAI_API_KEY` и при необходимости `BOT_REASONING_MODEL` подключают свободный текст. Для обычной формы CRM и структурированных ответов поставщиков ключ модели не требуется.
- `node tools/configure-telegram-webhook.mjs` по умолчанию показывает текущее состояние. Параметр `--apply` включает запись, а `--replace-existing` разрешает переключение с другого webhook.
- Для фоновых задач используйте Supabase Cron с pg_net. Сохраните в Vault `podbor_project_url` и `podbor_worker_secret`, совпадающий с секретом worker. Затем примените `schedule-workflow.sql`. Он ставит ежеминутный вызов /drain. Внешний планировщик с тем же вызовом также подходит.
- Уведомления об ожидании начинаются от подтверждённой доставки запроса. Начальные значения из прототипа составляют 2 часа для поставщика, 6 часов для менеджера и 2 дня для реакции клиента. Ответ, закрытие заявки и смена ответственного проверяются перед доставкой. Исходящие записи в состоянии uncertain или sending после сбоя требуют сверки с фактом доставки.
- Проверяйте первое подключение на согласованных тестовых Telegram-аккаунтах. Локальные тесты используют подмену Telegram API.

## Склад и объявления

По каждой новой заявке запускаются независимые задания. Настройки хранятся только в серверной переменной `SEARCH_ACCOUNTS`, в виде JSON-объекта по UUID компании. Для МоегоСклада используется `stock_token` с доступом к отчёту остатков. Поиск передаёт модель автомобиля, возвращает до 100 строк отчёта, проверяет остаток за вычетом резерва и переводит себестоимость из копеек в рубли.

Для партнёрской выдачи предусмотрены `market_url` и необязательный `market_token`. Адаптер выполняет HTTPS GET с параметром `model`. Ожидается JSON `{"rows":[{"name":"Toyota Camry","price":2800000,"currency":"RUB","term":"В наличии","url":"https://example.org/car/1"}]}`. Поставщик фида должен вернуть результаты по запрошенной модели. Без подключения можно сохранить ссылку на объявление вручную и перенести его в расчёт. Ошибка отдельного источника видна в карточке, повтор запускается кнопкой «Обновить поиск».

## Локальная проверка

`npm test` и `npm run test:bot` проверяют приложение, доступ, обработку текста и фото, адаптеры поиска и сборку PDF. На изолированном PostgreSQL выполните `tests/workflow-database.sql` под тестовыми ролями Supabase. `tests/workflow-browser.cjs` использует Chromium, настоящий обработчик Edge API и тестовый адаптер SQL поверх psql. Запускайте его только на временном кластере с приватным сокетом в /tmp/podbor-pg-sock-*, установленными схемами и ролями. WORKFLOW_ARTIFACTS задаёт каталог скриншотов и тестового PDF. Этот тест создаёт учебные записи в кластере.

Документация для подключения. [Остатки МоегоСклада](https://github.com/moysklad/api-remap-1.2-doc/blob/master/md/reports/_report_stock.md) · [Планировщик Supabase](https://supabase.com/docs/guides/functions/schedule-functions).
